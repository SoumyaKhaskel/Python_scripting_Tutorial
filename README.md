# 🐍 Python Scripting in 15 Days

**From Python fundamentals to practical automation — one day at a time.**

Welcome to my 15-day Python scripting learning series! This repository documents my journey of learning Python through hands-on coding, practical examples, and small automation exercises.

The goal is to build a strong foundation in Python scripting and understand how it can automate repetitive tasks in IT, system administration, data processing, and cybersecurity.

I'm learning in public, documenting each day's progress, and sharing the lessons on LinkedIn.

## 🎯 Learning Objectives

- Understand Python syntax, variables, data types, and control flow.
- Work with strings, collections, and reusable functions.
- Automate basic file and directory operations.
- Handle exceptions and validate user input.
- Build configurable command-line tools.
- Process CSV and JSON data.
- Interact with HTTP APIs.
- Analyze text and log files using regular expressions.
- Build a practical Python log analyzer.

## ⚙️ Requirements

- Python 3.10 or later recommended
- Windows, Linux, or macOS
- VS Code or another code editor
- A terminal for running scripts

Some later exercises will require internet access and the third-party `requests` package.

Check your Python installation:

**Windows PowerShell**

```powershell
py --version
```

**Linux/macOS**

```bash
python3 --version
```

## 🚀 Getting Started

### 1. Clone the repository

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR_USERNAME/python-scripting-15-days.git
cd python-scripting-15-days
```

### 2. Run a Python script

From the repository's root directory, use PowerShell on Windows:

```powershell
py .\day-01\first_script.py
```

Run the other available examples:

```powershell
py .\day-02\data_types.py
py .\day-03\strings.py
py .\day-04\data_structures.py
py .\day-05\conditions_loops.py
```

If the `py` command isn't available, try `python` on Windows or `python3` on Linux/macOS.

## 🧠 How to Use This Repository

For each lesson:

1. Read and understand the Python script.
2. Run it locally and inspect the output.
3. Modify values and experiment with the code.
4. Test invalid inputs and edge cases where relevant.
5. Complete the practical exercise.
6. Review the official documentation to deepen your understanding.

The goal is not just to copy code. It is to understand how it works and how to adapt it to solve practical problems.
